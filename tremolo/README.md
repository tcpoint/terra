## Controls
## Traditional
| Control | Description | Comment |
| --- | --- | --- |
| Knob 1 | Frequency | 0 - 20 Hz | 
| Knob 2 | Depth | 0 - 1 | 
| FootSwitch 1 | Effect On | Led On = Effect On | 

| sw1 | sw2 | sw3 | Waveform | 
| down | down | down | Sine |
| down | down | up |Triangle |
| down | up | down | Saw |
| down | up | up | Ramp |
| up | down | down | Square |
| up | down | up | Polyblep Triangle |
| up | up | down | Polyblep Saw |
| up | up | up | Polyblep Square |

| sw4 | effect |
| down | traditional |
| up | harmonic |
