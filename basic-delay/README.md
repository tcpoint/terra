# Basic Delay

Single delay with feedback and wet/dry control.

# Controls

| Control | Description | Comment |
| --- | --- | --- |
| Knob 1 | Delay Time | 50ms – 1s |
| Knob 2 | Feedback | Amount of signal fed back into the delay |
| Knob 3 | Wet/Dry | Mix between dry signal and delayed signal |
| Footswitch 1 | Bypass | LED on when effect is active |
| Audio In 1 | Audio Input | |
| Audio Out 1 - 2 | Mix Out | |
