# Zero — Flanger

## Controls

| Control | Description |
| --- | --- |
| Knob 1 | Delay time |
| Knob 2 | Feedback |
| Knob 3 | LFO manual offset |
| Knob 4 | LFO rate |
| Knob 5 | LFO depth |
| Footswitch 1 | On / off |
| LED 1 | On/off indicator |

## Waveform selection (Switch 1 + Switch 2)

| Switch 1 | Switch 2 | Waveform |
| --- | --- | --- |
| off | off | Triangle |
| off | on  | Sine |
| on  | off | Saw |
| on  | on  | Ramp |
